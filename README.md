🎮 UnLucky Holiday

UnLucky Holiday는
모바일 환경에서 플레이 가능한 탑다운 2D 도트 스타일의 운빨형 생존 게임입니다.
Vampire Survivors 장르(뱀서라이크)를 기반으로,
‘운’과 ‘컨트롤’의 균형을 핵심 재미로 설계한 게임입니다.

🕹️ 게임 개요

장르: 탑다운 2D 생존 액션 (Vampire Survivors-like)

플랫폼: Mobile (Android)

그래픽: 2D Pixel Art

엔진: Unity

플레이어는 무한히 펼쳐진 맵에서
사방에서 몰려오는 몬스터의 추적을 피하며 최대한 오래 생존해야 합니다.
몬스터를 처치해 얻은 전리품을 통해 플레이어를 성장시키고,
전리품속에 숨겨진 수집 아이템을 모두 모아 보스 몬스터를 소환 및 처치하는 것이 최종 목표입니다.

🔁 핵심 플레이 루프

무한 맵에서 몬스터의 추적을 피하며 생존

몬스터 처치 → 전리품 획득

전리품을 통한 플레이어 성장

맵에 배치된 수집 아이템 획득

모든 수집 아이템을 모아 보스 몬스터 소환

보스 처치 후 기록에 도전

수집 아이템은 성능 강화를 위한 요소가 아닌,
보스 몬스터를 소환하기 위한 핵심 조건으로만 사용됩니다.

🎯 게임의 핵심 컨셉
운 (Luck)

아이템에는 등급 시스템이 존재하며
높은 등급의 아이템일수록 성능은 강력하지만 드랍 확률은 낮게 설계되어 있습니다.

운이 좋다면 빠른 성장이 가능하며,
보스 몬스터에도 비교적 이르게 도전할 수 있습니다.

컨트롤 (Control)

몬스터는 시간이 지날수록 점점 강해지고, 수적으로도 증가합니다.

플레이어의 이동 경로 선택과 회피 컨트롤이 부족할 경우
좋은 아이템을 획득했더라도 쉽게 게임 오버에 도달합니다.

➡️ 운만 좋아도, 컨트롤만 좋아도 클리어할 수 없는 구조를 목표로 설계했습니다.

🏆 랭킹 시스템

플레이 결과를 기반으로 한 랭킹 시스템을 도입하여
타 유저와의 간접적인 경쟁을 유도했습니다.

최고 기록(생존 시간 기준)을 중심으로 랭킹 집계

더 높은 기록에 도전하도록 동기를 제공

반복 플레이를 자연스럽게 유도하여
모바일 환경에서의 플레이 타임 증가를 목표로 설계

📌 기획 의도

UnLucky Holiday는
단순한 운빨 게임이 아닌,
확률적 성장 요소 위에 플레이어의 조작 실력이 결과에 직접적으로 영향을 미치는 구조를 목표로 개발되었습니다.

운에 의해 달라지는 매 플레이 경험

컨트롤 실수 하나로 뒤집히는 긴장감

기록 경쟁을 통한 지속적인 도전 욕구

이를 통해 매 판마다 다른 선택과 흐름을 만들어내는
재도전 가치가 높은 생존 게임을 지향합니다.

📂 개발 목적

본 프로젝트는
게임 회사 취업을 위한 포트폴리오용 개인 프로젝트로 제작되었으며,

Unity 기반 모바일 게임 개발 경험

생존 게임 구조 설계

랭킹 시스템 및 데이터 관리

실제 스토어 배포 및 테스트 경험

을 목표로 개발되었습니다.
